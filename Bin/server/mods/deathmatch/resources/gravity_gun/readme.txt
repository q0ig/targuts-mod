Main changes to the original:
-i have restricted the gravity gun effect to just one weapon id 27.
-changed gravity gun mechanics and usage a bit
-fixed some minor exceptions, made the script easy to use.
-applied model, shaders and sounds.

To use:
-start the script
-get SPAZ-12 Combat
-aim weapon at the vehicle, ped or object
-push 'left mouse button' to hold
-hold 'left shift' to grip element at it's original distance (peds and vehicles)
-'left alt' loads the amount of force to throw the object
-if 'left alt' is held when 'left mouse button' is pushed the force bar is maxed
-mouse roll lets you rotate the vehicle at xy axis
-hold 'left shift' while scrolling mouse wheel to change element distance
-push again to release
